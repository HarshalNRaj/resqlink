    Project boundaries

    What this flow does—and does not do

    The animation follows the project’s real API and component boundaries. It does not fill in unfinished modules or claim features the code does not implement.

    ◎

    Delivery updates, not live GPS

    Volunteers claim an accepted delivery and record pickup, out-for-delivery, and delivered statuses. Request status views refresh periodically; there is no WebSocket, route planner, ETA engine, or live location feed.

    POST /api/requests/<id>/delivery
    ⌖

    Opt-in approximate organization pins

    Leaflet renders OpenStreetMap tiles. Browser location is used only after a user action; organization markers require an approved organization to share rounded service-area coordinates.

    GET /api/nearby · Nominatim geocoding
    ◇

    Blood bank directory, not inventory

    Blood banks can register, be verified, maintain profile details, and appear in the nearby directory. There is no implemented blood-stock API, reservation, or donor appointment workflow.

    MongoDB users profile · no inventory route
